  frozen study tests pass. Separate maintenance branch: **2,546 passed /
  9 xfailed** in its main suite and **59 passed / 2 explicitly deselected** in

metadata in the new regression tests; the remaining warning is the existing

behavior changes are rejection of malformed new diagnosis/governance inputs,
blocking mutated letter metadata, stricter UI acknowledgement, and fail-closed
diagnostics for unreadable UTF-8 drift logs. These results are synthetic
non-regression evidence, not clinical validation.
