# v2.7.1 — per-course resolution of CPB 0236 therapy courses (candidate)

Engine/app version is **2.7.1**; record `schema_version` remains **2.0.0**. Prepared for review in its own pull request. Not merged, tagged or deployed.

## What changed

Lumbar MRI pathway (Aetna CPB 0236) only. The class-name therapy pattern ("NSAIDs for 8 weeks with no improvement") used to accept a course anywhere in a clause. Words around it were ignored unless they matched a fixed list of disqualifiers, so "Missed NSAIDs…", "In 2019, NSAIDs…" and "Intermittent NSAIDs… taken twice total" were all asserted as `MET`.

Now each class-name course is classified:

- **Clean:** the clause is fully accounted for by a closed course grammar. Behaviour is unchanged.
- **Response uncertain:** extra words follow the response in the same clause. The duration stands and the response goes to `NEEDS_REVIEW`.
- **Course uncertain:** extra words come before or inside the course, or a separate non-therapy clause in the sentence comments on it. The course is set aside.

A clean course decides both facts on its own unless a set-aside course is longer than it, in which case both facts go to `NEEDS_REVIEW` (owner decision, Option A). A non-therapy clause in the same sentence sends the course to review unless it is one of a closed set of clearly independent statements, such as an MRI request or a referral. Extraction still does not know payer thresholds. Courses already marked ambiguous by earlier rules keep their existing behaviour. Other pathways, the drug-name patterns and the objective-exam extractor are unchanged.
