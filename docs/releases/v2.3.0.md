# v2.3.0 — bounded extraction fixes and explicit open gaps

Engine/app version is **2.3.0**; record `schema_version` remains **2.0.0**.
This release packages exp-001 through `3f81277`, then updates documentation,
versioning and test bookkeeping. No new product logic was added in the release
preparation pass. Rules, policy snapshots, monitoring timestamps and runtime
freshness semantics remain unchanged. The PR is for review; no merge or tag is
part of this preparation.

## Five accepted fixes

| Fix | Result | Regression evidence |
| --- | --- | --- |
| Auxiliary-verb diagnosis negation | `does/do/did not have` before lumbar pain or radiculopathy produces False; conflicting affirmative/negative proposals require review. | `negation_first` contract example and nine diagnosis cases |
| Reflex descriptor linkage | Pain/sensation adjectives cannot establish a reflex change merely because a reflex noun appears elsewhere in the clause. Require a bounded reflex noun/predicate link. | `reflex_attribution` and 14 reflex/attribute cases |
| Intact reflex recognition | Explicit intact root-distribution reflexes produce a normal finding / NOT_MET rather than missingness. Uncertainty and conflicts still review. | independent case 18 and seven intact-reflex cases |
| Negated numeric strength | A denied number is reviewed before threshold comparison; `not 4/5` establishes neither observed weakness nor normal strength. | eight numeric-strength cases |
| Cross-sentence sleep-study date association | An appointment date in another sentence cannot supply missing study-date evidence. | `borrowed_date`, the attested G07 check and seven date/citation cases |

See [autoloop/REPORT.md](../../autoloop/REPORT.md) and
[LOG.md](../../autoloop/LOG.md) for before/after failures, rejected first attempts,
accepted commits, metric/canary comparisons and limitations. The unchanged
45-case authored set improves from 35/45 to 45/45 with false pending 10 → 0.
The expanded 47-case set includes two remaining setup counterexamples and scores
45/47, false pending 12 → 2. The 52-case corpus remains 52/52, false pending zero.
These authored regressions are not held-out validation. The always-abstain
canary also has zero false pending, so that count alone demonstrates no gain.

An external held-out set (41 cases, not visible during development) scored before and after: false PENDING_VERIFICATION 1 → 0, no other status changes.

That external result was supplied by the owner; its cases were not inspected or
rerun during this release preparation. It does not establish clinical validity.

## Contract bookkeeping and remaining gaps

Removed `known_failure` from `negation_first`, `reflex_attribution` and
`borrowed_date`; their expected facts/statuses are unchanged. Removed the
hardcoded exemption set from the contract test. JSON now solely determines
strict markers. Added correct-value `known_failure` examples for:

- `has neither low back pain nor radiculopathy` → expected False / NOT_READY;
  currently an unsafe affirmative proposal.
- Same-sentence unrelated visit date → expected null / CANNOT_DETERMINE;
  currently an unsafe date proposal.

There are ten strict xfails: four contract examples (including unrelated therapy
and the disputed negated-strength label), two cross-sentence temporality tests,
generic analgesic duration and three H1(a) next-line/laterality/copy-forward
checks. False READY remains possible with incorrect human attestations. The
neither/nor lumbar case can also achieve submission readiness with current
verified governance; the CPAP date case remains under demo trust.

The bounded reflex vocabulary and 160-character lookback can under-capture
legitimate wording. The date rule does not solve two events in one sentence
and can miss genuine cross-sentence date linkage. None of the five fixes solves
an entire negation, attribution or temporality class.
